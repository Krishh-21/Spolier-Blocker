═══════════════════════════════════════════════════════════
COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════

ISSUE: v4Active = false
FIX:
  1. Open Console
  2. Look for "[V4 BRIDGE]" logs
  3. Check for error messages
  4. Verify all 5 V4 files loaded
  5. Reload extension

ISSUE: All tests show "Spoiler: false"
FIX:
  1. Check: window.SpoilerShieldV4.isActive()
  2. Run: testV4.debug()
  3. Verify knowledge engine initialized
  4. Check: typeof KnowledgeEngine !== 'undefined'

ISSUE: Benchmark shows 0% precision
FIX:
  1. Check initialization logs
  2. Verify detector loaded
  3. Run single test: testV4.analyze('test', ['media'])
  4. Check error logs: window.__V4_DEBUG.errors

ISSUE: Performance is slow
FIX:
  1. Run: testV4.stats()
  2. Check avgProcessingTime
  3. Should be < 15ms
  4. If higher, check knowledge base size
