LOAD EXTENSION → OPEN DEVTOOLS → RUN TESTS

=====================================================

Run in console:

  processTextCalls: > 0,

TEST 2: BLOCK-LEVEL BLUR TEST
=====================================================

Run in console:
window.__V3_TEST()

What happens:
1. Yellow box appears with 5 spoiler sentences
2. Extension analyzes the content
3. Block-level blur should be applied
4. Results shown in console after 1 second

✅ SUCCESS if console shows:
"✅ TEST PASSED: Block-level blur applied"
AND
blockBlurs: > 0
escalatedBlocks: > 0

⚠️ PARTIAL if console shows:
"⚠️ PARTIAL: Some blurring occurred, but not block-level"
(Means span-level blur worked but escalation didn't trigger)

❌ FAILURE if console shows:
"❌ TEST FAILED: No spoiler detection"

=====================================================
DEBUGGING ESCALATION LOGIC
=====================================================

If block blurs aren't triggering, check:

1. Are you tracking the media?
   - Go to Options → Media Library
   - Verify the show/movie is selected

2. Is the content relevant?
   - Text must mention tracked titles
   - Or contain character names

3. Check escalation thresholds:
   - Needs 3+ signals OR
   - Needs 2+ major signals OR
   - Needs 25%+ spoiler density

4. Check console logs:
   Look for: [V3.7 ESCALATION] messages
   If missing → escalation not triggered
   If present → escalation triggered

5. Inspect blurred elements:
   Right-click blurred content → Inspect
   Look for attributes:
   - data-spoiler-block-blur="true"
   - data-spoiler-signal-count="X"
   - data-spoiler-density="X"

=====================================================

    blockSpoilersDetected: X,

    escalatedBlocks: X

If avgProcessingTime > 15ms:
- Performance degradation
- May need optimization

If < 15ms:
- ✅ Performance target met

TROUBLESHOOTING
=====================================================

PROBLEM: processTextCalls = 0
FIX: V3 loaded but not processing. Check bridge initialization.

PROBLEM: blurCalls = 0
FIX: Processing but not detecting. Add media to track list.

PROBLEM: blockBlurs = 0, but should escalate
FIX: Check escalation thresholds. May need 3+ signals.

PROBLEM: Everything = 0
FIX: 
1. Reload page
2. Check console for errors
3. Verify V3 files loaded
4. Run window.__V3_TEST()
