═══════════════════════════════════════════════════════════════
                      HOW IT WORKS
═══════════════════════════════════════════════════════════════

  STEP 1: User visits landing page
          │
          ├─ JavaScript detects if extension installed
          │
          └─ Shows "Sign In" or account info

  STEP 2: User clicks "Sign In"
          │
          ├─ Landing page asks extension to open settings
          │
          └─ Extension settings page opens

  STEP 3: User signs in with Google (in extension)
          │
          ├─ Extension stores account in chrome.storage.sync
          │
          └─ Notifies landing page of account change

  STEP 4: Landing page updates automatically
          │
          ├─ Fetches account from extension
          │
          └─ Displays user name, email, avatar

═══════════════════════════════════════════════════════════════
                      TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

  ❌ "Sign In" button doesn't work
     → Check if extension is installed
     → Check browser console for errors
     → Verify manifest.json has externally_connectable

  ❌ Account doesn't appear
     → Sign in through extension first
     → Refresh landing page
     → Check extension ID is correct

  ❌ Dropdown doesn't open
     → Check CSS is loaded
     → Check JavaScript has no errors
     → Try clicking account again

  ❌ "Extension not found" error
     → Extension must be installed first
     → Check URL is allowed in manifest.json
     → Try localhost or file:// URL
