PROBLEM SOLVED:
---------------
BEFORE V3.7:
- Article with 10 spoiler sentences
- Only 2-3 sentences blurred
- User can still read 7-8 spoilers
- SPOILER LEAKAGE = User gets spoiled

AFTER V3.7:
- Article with 10 spoiler sentences
- ENTIRE BLOCK blurred if:
  * 3+ spoiler signals detected
  * 2+ major signals (death, ending, twist)
  * 25%+ sentences are spoilers
  * Block probability >= 80%
  * AI/spoiler content type detected
- NO SPOILER LEAKAGE = User stays safe

=====================================================
NEW IN V3.7:
=====================================================

1. BLOCK-LEVEL ANALYSIS
   - Splits text into sentences
   - Analyzes spoiler density per block
   - Counts major vs minor signals
   - Detects narrative density
   - Identifies content type (AI response, article, etc.)

2. SMART ESCALATION RULES
   Blur entire block if:
   ✓ signalCount >= 3
   ✓ majorSignalCount >= 2  
   ✓ spoilerDensity >= 0.25 (25%+ sentences)
   ✓ blockProbability >= 0.80
   ✓ narrativeDensity >= 0.30
   ✓ AI response with 2+ signals

3. MAJOR SIGNALS (Critical Spoilers)
   - death, ending, revelation
   - outcome, transformation, villain
   
4. CONTENT BLOCK DETECTION
   - Finds appropriate parent element
   - Targets: <p>, <div>, <article>, <section>
   - Identifies: comments, posts, messages
   - Avoids: page containers, body, main

5. BLOCK TYPE CLASSIFICATION
   - aiResponse: "as an ai", "i can't provide"
   - spoilerRequest: "tell me the ending"
   - plotSummary: "plot summary", "synopsis"
   - endingDiscussion: "ending", "finale"
   - characterDeaths: "who dies"
   - outcomeDiscussion: "who wins"

=====================================================
ESCALATION RULES IN DETAIL:
=====================================================

Rule 1: High Signal Count
if (signalCount >= 3) → BLUR BLOCK
Example: "dies", "ending", "twist" = 3 signals

Rule 2: Major Signals
if (majorSignalCount >= 2) → BLUR BLOCK
Example: "dies", "killed" = 2 major signals

Rule 3: Spoiler Density
if (spoilerDensity >= 0.25) → BLUR BLOCK
Example: 2 of 8 sentences = 25% = BLUR

Rule 4: Block Probability
if (blockProbability >= 0.80) → BLUR BLOCK
Example: Average sentence probability = 0.85 = BLUR

Rule 5: Narrative Density
if (narrativeDensity >= 0.30) → BLUR BLOCK
Example: 30%+ narrative indicators = BLUR

Rule 6: Content Type + Signals
if (type = AI response AND signals >= 2) → BLUR BLOCK
Example: ChatGPT response with 2 spoiler signals = BLUR

└─ NO (low signal count, low density)
   ↓
   detectSpoilerSpans()
   ↓
   wrapTextSpoiler()
   ↓
   SPECIFIC SPANS BLURRED
   spanBlurs++
