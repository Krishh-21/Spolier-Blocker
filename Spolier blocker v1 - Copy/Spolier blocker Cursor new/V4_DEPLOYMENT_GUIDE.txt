WHAT CHANGED FROM V3 TO V4
═══════════════════════════════════════════════════════════

V3 ARCHITECTURE (REGEX-BASED):
  User tracks "Avengers: Endgame"
  ↓
  Generate phrase list: ["Tony Stark", "Iron Man", "Thanos"]
  ↓
  Build regex: /\b(Tony Stark|Iron Man|Thanos)\b/i
  ↓
  Match patterns + weighted scoring
  ↓
  Blur if threshold met

PROBLEMS WITH V3:
  ❌ "Cap gets his dance" → NOT DETECTED (no keyword)
  ❌ "Verstappen wins Monaco" → NOT DETECTED (not tracked)
  ❌ Tony Stark ≠ Iron Man (separate entities)
  ❌ No context understanding

V4 ARCHITECTURE (INTELLIGENCE-BASED):
  User tracks "Avengers: Endgame"
  ↓
  Load Knowledge Base:
    - Characters: Tony Stark = Iron Man
    - Events: death, victory, ending
    - Narratives: "Cap gets his dance" = ending
  ↓
  Analyze text with intelligence:
    - Entity matching
    - Event detection
    - Narrative inference
    - Relevance checking
  ↓
  Blur only if relevant + spoiler detected

V4 UNDERSTANDS:
  ✅ "Cap gets his dance" → DETECTED (narrative)
  ✅ "Tony Stark dies" = "Iron Man dies" (entity matching)
  ✅ "Verstappen wins Monaco" → DETECTED (F1 knowledge)
  ✅ Context: Only blur if related to tracked media
